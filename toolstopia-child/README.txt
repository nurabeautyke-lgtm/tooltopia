TOOLSTOPIA CHILD THEME (v1.1.0)

WHAT IT DOES
- Keeps your current parent "Toolstopia" homepage and design exactly as they are.
- Automatically creates or updates all information pages with detailed, designed content:
  About Us, Shipping Policy, Returns & Refund Policy, Delivery & Installation,
  Contact Us, FAQ, Why Choose Tools Topia.
- Removes the word "card" from the product-page payment line.
- Does NOT touch your homepage, and does NOT create Service Centre or Careers pages.

HOW TO USE
1. Appearance > Themes > Add New > Upload Theme > choose this zip > Install > Activate.
   IMPORTANT: this child needs its parent. "Template: toolstopia" must match the parent
   theme folder name exactly. If activation says the parent is missing, tell your developer
   to change that one line to the real parent folder name (or use the PLUGIN instead - easier).
2. After activating, a green notice appears in wp-admin listing every page it set up,
   each with a "view page" link so you can confirm the changes.
3. Edit any page later in Pages - your edits are kept.

TIP: If you prefer not to change your theme at all, use the "Tools Topia Pages" PLUGIN
instead. It does the same thing without touching your theme.
